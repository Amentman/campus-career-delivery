# 校招交付团队复用计划

目标：团队从同一个公开仓库安装完整业务Skill，配置一次私有资源入口，后续版本可以安全更新。

采用标准库Python工具；成员身份与团队资源分离。公开包不携带作者私人目标或持续授权。每个Skill可单独复制，所需配置说明放在其目录内。

1. 先补齐缺配置、单Skill安装与已有本地改动的行为测试，再实现配置/安装/诊断工具。
2. 逐个读取现有Skill和直接引用；按新人首次使用情景修复，保留原业务内容和实际验收要求。
3. 更新目录、来源、插件清单、脱敏规则与文件哈希。检查所有本地来源，第三方能力保留上游归属。
4. 生成私有团队路由配置示例和实际交接包。每位成员使用自己的登录态，不复制凭据，不自动授予权限。
5. 同步器只处理白名单源，按已发布源与公开版的映射做增量；新私密内容或并发修改先保留冲突，不强制覆盖。
6. 使用干净目录安装并回读目标；运行全部现有测试、配置异常路径、敏感信息检查和独立复用测试。通过后发布并核对公开远端。

受保护对象：原工作树未提交成果、已有个人运行配置、所有学生/客户数据、飞书页面与权限。公开同步只含规则、引用、脚本和合成测试。
