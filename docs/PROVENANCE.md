# 来源与可移植化说明

本轮同步日期：2026-11-02（Asia/Shanghai）。本仓库包含18个与学生求职交付、跟进、销售和内容生产直接相关的Skill。来源为当前运行版及此前公开副本；原始个人Skill保持不变。

## 本轮更新

- 13个原有核心Skill与当前运行版重新核对，补齐共享岗位池、校招/实习/社招模式、逐岗终审、面试逐题完整答案、正文图片与交付验收规则。
- 新增学生多源跟进、综合待办、求职销售、求职内容发布和小红书图片渲染5个配套Skill，包含相关脚本、引用和测试。
- 保留此前工作区未提交的作品集首屏总览、固定基础资料、专岗正文图片、浏览器恢复和本人名下交付规则。保留公开版既有的两个岗位表兼容脚本。
- 当前全局和项目规则经脱敏后更新到 `prompts/`；项目入口同时更新。每个Skill完整目录及提示词的SHA-256记录在 [SYNC_MANIFEST.json](SYNC_MANIFEST.json)。

## 公开版与个人运行版的差异

- 本机绝对路径改为相对路径、用户配置或占位符；文档中的 `scripts/...` 相对所在Skill目录执行。跨Skill的Markdown引用使用仓库内相对链接。
- 删除本人账号、open_id、应用标识、私人飞书URL、节点/Base/table/record标识、协作人员与真实部署历史。测试使用明显的合成父节点。
- 待办合同不继承作者的每日运行时间、持久授权或已完成任务清单；当前使用者自行确认目标、时间与权限。共享岗位池写回同样需要当前使用者的明确授权。
- 销售知识库由使用者自行提供；微信读取通过使用者已授权的连接器或本地导出，不分发原作者的私人解析器、聊天数据或凭据。
- 使用者需要自行安装Word/PDF、设计、浏览器和飞书等工具。安装Skill不等于这些外部能力已接通。
- 发布测试使用 `fileURLToPath` 正确解析含中文或空格的安装路径；图片Skill的合同测试与当前“锁定模板直接渲染、授权设计变更才调用设计技能”的规则一致。

## 验收边界

仓库检查涵盖目录完整性、YAML格式、本地引用、敏感模式、文件指纹和附带脚本的自动测试；它不代表某位学生的材料已经生成，也不替代真实业务来源、外部写后回读或视觉验收。
