# 顾问式完整求职规划打法

用于销售咨询中的方向引导、已有规划的案例学习、行业解释或顾问／家长沟通稿。用户要正式完整学生规划时转 `delivering-student-career-plans`；本参考不另起正式交付合同。

## 文档模式

用户要求正式学生规划时转专门 Skill；只要求“由顾问讲解”的沟通稿时，按本次范围适配已有规划，参考以下语态：

- 使用第三人称或无主语表达，不使用“你”“同学”“我认为”等对话语态。
- 使用“候选人定位为”“建议优先考虑”“匹配依据包括”“准备重点为”“阶段目标为”等标准化表述。
- 不写顾问讲解词、销售推进话术或服务价值收束；这些内容仅在用户明确要求内部销售稿时补充。
- 表格字段使用 `优先级｜行业与岗位｜匹配依据｜目标公司池｜准备重点`。
- 章节和岗位优先使用中文，必要的技术名词首次出现时补充中文含义。

## 视觉模式验收

### 短回复保持短

输入：“这个客户问价格后没回，我微信怎么跟进？”用户只要可复制话术。输出仍是一张短销售行动卡或一段话，不加载长文档视觉流程；内部记录 `no_visual_reason: 短微信回复，没有复杂关系需要图解`。不得为了显得专业而增加漏斗图、客户画像图或附件。

### 完整家长版规划使用关系图

输入包含候选人背景、毕业时间、主攻／保稳／条件性拓展方向，并明确要求完整家长版报告。输出保留可独立转发的五列核心表，同时规划：

- 主攻／保稳／条件性拓展路线图，注明进入与换线条件；
- 目标公司与投递阶段漏斗，仅在阶段转化确实影响决策时使用；
- 项目—简历—投递—面试服务交付路径；
- 基于毕业时间和招聘窗口的时间线。

所有图解使用 `visual-document-delivery`，紧邻对应章节并完成最终格式逐页验收。真实客户姓名、联系方式、合同、内部价格、未核验结果和当前 HC 不进入图解；公司池仍是方向，不是招聘承诺。

## 必须遵守

- 先用 1-2 句话讲清个人定位和岗位逻辑，再给学生方向。
- 先收窄主线，再扩展备选，不要一上来列很多“都可以”。
- 以表格为主，段落为辅。表格后用短段落解释关键判断。
- 每个推荐方向都要落到：行业与岗位、为什么适合、公司池、怎么准备。
- `怎么准备`按真实缺口选择深挖既有经历、必要知识训练或补充项目，写清动作、产物和验收，再关联简历版本或面试案例。成熟履历不强制新增项目，不能只写“补数据、加强英语、准备案例”。
- 公司池用于帮助建立投递范围，不代表当前有 HC；动态招聘信息需要另行核验。
- 薪资、HC、扩招只能谨慎表述；没有可靠来源时用“可关注/通常区间需以岗位为准”，不要承诺。
- 输出结尾必须有行动收束：学生交付版使用“近期重点事项”，顾问沟通稿可以使用“现在立刻做的三件事”。

## 完整规划图解合同

只有完整规划文档、完整报告或家长版报告才进入图解规划。使用 `visual-document-delivery`，按实际关系选择：

1. **路线图：** 主攻、保稳、条件性拓展与暂不建议方向，展示支持证据、进入条件和换线条件；路线是建议，不是已收到的机会。
2. **公司池／投递漏斗：** 当投递阶段、筛选条件或转化复盘会改变行动时，展示“研究池 → 已核验岗位 → 已投递 → 面试 → 复盘／补投”。公司池不等于当前 HC，未读取真实台账时不填虚构数量。
3. **交付路径：** 把对口项目、简历版本、投递和面试串成可验收路径，说明每一步的产出；服务动作不能画成学生已经完成的经历或结果。
4. **时间线：** 基于毕业日期、应届身份和真实招聘窗口，展示准备、实习、秋招／春招与复盘节点；动态窗口注明核验日期。

五列核心规划表必须保持独立可转发，图解只解释表格难以表达的关系。每张图紧邻对应章节；最终格式逐页检查正常缩放下的字号、裁切、图例、宽表和图文分离。

图解不得包含真实客户姓名、联系方式、合同、录制信息、内部价格、未授权案例或未核验结果。使用脱敏标签；销售内部判断与学生可见正文分开。

## 默认精简完整结构

除非用户明确要求详细报告，默认按以下结构输出：

1. 核心定位：1-2 句话。
2. 核心规划表：3-5 个方向。
3. 不建议方向：只写 1-3 个关键排除项。
4. 投递节奏或应届身份：仅在毕业时间会影响投递时输出。
5. 近期重点事项。

核心规划表固定使用：

| 优先级 | 行业与岗位 | 为什么适合 | 公司池 | 怎么准备 |
|---|---|---|---|---|

`怎么准备`推荐句式：

`补一个“【项目名称】”项目，完成【模块1、模块2、模块3】，形成【作品集/报告/看板/方案】；同步制作【岗位版简历】并沉淀为面试案例。`

不要在表后重复列一套与表格脱节的项目建议。

## 详细报告结构

只有用户明确要求“完整报告”“给家长版本”“岗位科普”时，才继续展开以下内容。

### 1. 开场定位

先用 2-3 句话定义候选人：

- `候选人的核心定位为：【行业理解】+【技能】+【岗位场景】的复合型候选人。`
- 指出当前核心矛盾：方向太散、缺实习、缺项目深度、缺面试故事、或需要就业/读博取舍。

### 2. 个人信息提炼表

用表格提炼，不要散写：

| 维度 | 关键信息 | 对求职的影响 |
|---|---|---|
| 学历/专业 |  |  |
| 毕业时间/应届身份 |  |  |
| 实习/项目 |  |  |
| 技能/语言 |  |  |
| 性格/偏好 |  |  |
| 城市/行业 |  |  |

### 3. 就业市场现状

先讲大环境，再讲候选人应该避开什么。

非技术规划常用判断：

- 职能岗 HC 少，受降本和 AI 影响较明显，不适合作为多数转行学生主线。
- 运营/市场/商业化岗位面更宽，但需要业务结果和沟通表达。
- 产品、运营、市场边界变模糊，候选人要讲清自己面向什么用户、做什么指标、推动什么结果。
- 策略/数据/商分岗位更看学历、实习、逻辑表达和业务理解。

技术规划常用判断：

- 纯算法岗竞争强，项目/论文/实习要求高。
- 普通嵌入式岗位稳定但天花板和赛道差异大。
- AI 落地、机器人、边缘计算、智能硬件、自动驾驶、AI 芯片软件更适合有复合项目的同学。

### 4. 岗位科普

必须解释岗位真实做什么，避免学生只知道岗位名。

表格模板：

| 岗位方向 | 真实工作内容 | 看重能力 | 适合人群 | 风险 |
|---|---|---|---|---|
| 产品运营/用户运营 | 用户反馈、活动、留存、需求传递、数据复盘 | 沟通、用户理解、数据意识 | 有内容/活动/VOC/项目推进经历 | 容易泛，需要业务案例 |
| 数据/策略运营 | 指标体系、SQL、异常归因、分析报告 | SQL、逻辑、业务理解 | 数据实习强、表达好 | 容易变成报表岗 |
| 商业化/行业运营 | 商家增长、品类机会、广告收入、Big Day | 生意理解、项目推进 | 商科、沟通强 | 压力和指标导向强 |
| 出海/GTM | 海外渠道、营销、产品上市、国家市场 | 英语、跨文化、项目管理 | 海外背景/英语好 | 需要本地化案例 |

### 5. 目标赛道与岗位优先级

使用“第一梯队/第二梯队/第三梯队”或“主攻/保稳/拓展”，表格必须包含：

| 优先级 | 行业与岗位 | 为什么适合 | 公司池 | 怎么准备 |
|---|---|---|---|---|

写法：

- 第一梯队：最贴合背景，最值得投入。
- 第二梯队：胜率和岗位面更稳。
- 第三梯队：兴趣/上限/保底，不能喧宾夺主。

### 6. 简历版本

按实际目标岗位和表达差异决定简历版本数量；一个明确目标不机械增至两版或三版：

| 简历版本 | 用途 | 重点突出 | 弱化内容 |
|---|---|---|---|

示例：

- 数据运营版：SQL、指标、看板、VOC、业务建议。
- 产品运营版：用户需求、竞品、功能反馈、跨部门推进。
- 出海版：英语、海外用户、本地化、KOL、跨境平台、GMV/ROI。
- 技术岗见 `technical-career-planning.md`。

### 7. 时间线

必须基于当前日期和毕业日期输出。不要写空泛“尽快准备”。

| 阶段 | 时间 | 核心目标 | 行动清单 | 产出 |
|---|---|---|---|---|

常见阶段：

- 立即：定方向、改简历、补项目、启动投递。
- 实习窗口：用 1-2 段实习验证岗位可行性。
- 秋招前：面试题、案例库、作品集、岗位池。
- 秋招期：提前批、正式批、复盘、补投。

### 8. 面试和项目准备

核心项目已经写入五列规划表。用户要求展开时，再按岗位拆：

| 岗位 | 必备案例 | 面试重点 |
|---|---|---|

非技术常见案例：

- 用户增长/留存复盘。
- VOC 用户反馈分析。
- 活动转化/投放复盘。
- 竞品分析和需求优先级。
- 品类/商家/GMV 增长案例。

### 9. 服务化收束

仅内部销售沟通稿在本次范围内关联已确认的服务价值；正式学生正文不加入销售收束：

- 方向定位：把主线和备选线定清楚。
- 简历版本：做不同岗位版本。
- 项目补强：按照核心表为不同岗位补互联网/出海/AI/电商/技术项目，形成能写进简历、能用于面试的作品和案例。
- 投递策略：岗位池、城市、公司层级、复盘。
- 面试训练：行为面、业务案例、技术题、案例面、群面。
- 实习中复盘：任务拆解、职场沟通、成果包装。

## 输出风格

- 不写鸡汤，不写“完美匹配”。
- 不要在没有来源时写固定薪资。
- 不要说“你一定能进大厂”。
- 多用“主攻、保稳、拓展”“现阶段先”“后续再”。
- 默认先给可直接转发的核心表；详细规划再补岗位科普、时间线和可发送话术。
