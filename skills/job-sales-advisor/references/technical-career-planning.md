# 技术岗与读博双轨规划

用于技术学生、工科学生、AI/机器人/嵌入式/自动驾驶/芯片/读博规划。必须区别于非技术岗模板。

## 技术规划核心问题

先判断候选人是以下哪类：

- 纯算法：CV/NLP/多模态/深度学习，要求论文、比赛、开源、强实习。
- 算法工程化：模型部署、性能优化、推理加速、边缘 AI。
- 嵌入式/系统软件：C/C++、Linux、RTOS、驱动、通信协议、系统测试。
- 机器人/自动驾驶：感知、控制、规划、SLAM、ROS2、传感器融合。
- AI 芯片/半导体软件：FPGA、工具链、编译器、模型部署、验证。
- 读博科研：研究问题、论文、RA、导师推荐、SOP/Research Proposal。

## 技术方向优先级表

技术规划也先输出统一的核心表，但“怎么准备”必须按技术项目写，不能只列复习科目：

| 优先级 | 行业与岗位 | 为什么适合 | 公司池 | 怎么准备 |
|---|---|---|---|---|
| 主攻 |  |  |  |  |
| 保稳 |  |  |  |  |
| 拓展 |  |  |  |  |

`怎么准备`推荐句式：

`补一个“【技术项目】”，完成【系统架构、核心模块、测试/部署】，对比【准确率、延迟、FPS、资源占用、功耗或稳定性】指标，形成【GitHub/技术报告/Demo】；同步重构【岗位版技术简历】并准备项目深挖。`

公司池代表赛道匹配，不代表当前有 HC。补充项目必须如实标注为项目或作品，不能虚构公司经历、生产数据或性能结果。

判断原则：

- 有 AI + 硬件/嵌入式项目：优先看边缘 AI、嵌入式 AI、机器人系统。
- 有图像/多模态但论文弱：算法岗可拓展，不宜唯一主线。
- 有华为/大厂工程实习：突出工程规范、测试框架、性能优化、生产级代码。
- 有 FPGA/STM32/ESP32/Arduino：突出端侧部署、硬件约束、系统集成。

用户说关注国内时，减少新加坡/海外篇幅，把海外硕士作为背书：

| 国内赛道 | 目标岗位 | 公司类型 | 准备重点 |

| 智能汽车/自动驾驶 | 感知算法、车载嵌入式、系统软件 | 主机厂、自动驾驶、Tier1 | CV、C++、Linux、系统设计 |

## 技术简历版本

| 简历版本 | 主打岗位 | 必须突出 | 弱化 |
|---|---|---|---|
| 边缘 AI 版 | 嵌入式 AI、模型部署 | 模型、硬件平台、延迟、资源占用、优化对比 | 泛泛课程经历 |
| 机器人版 | 机器人软件、控制/感知 | 系统架构、传感器、控制逻辑、测试指标 | 纯软件无关内容 |
| 嵌入式版 | C++/嵌入式/系统软件 | STM32、ESP32、RTOS、通信协议、gtest、Linux | 算法概念堆砌 |
| 算法版 | CV/多模态/自动驾驶感知 | 数据集、模型结构、训练、指标、误差分析 | 只有调用模型的描述 |
| 读博版 | PhD/RA/Research Engineer | 研究问题、方法、实验、导师/课题、论文潜力 | 商业化包装 |

## 项目深挖模板

每个技术项目都要能回答：

| 维度 | 问题 |
|---|---|
| 背景 | 为什么做这个项目？解决什么技术问题？ |
| 架构 | 系统由哪些模块构成？数据流/控制流是什么？ |
| 个人贡献 | 你负责哪部分代码、硬件、算法、测试？ |
| 难点 | 最大技术难点是什么？你怎么解决？ |
| 指标 | 准确率、延迟、FPS、资源占用、功耗、稳定性、成功率有什么结果？ |
| 复盘 | 如果重做，怎么优化？ |

## 技术面试知识树

按方向给准备项：

| 方向 | 必备知识 |
|---|---|
| 通用技术 | 数据结构与算法、C++、Python、操作系统、Linux、计算机网络基础 |
| 嵌入式 | STM32、RTOS、中断、I2C/SPI/UART、GPIO/PWM/ADC、内存和功耗 |
| 边缘 AI | 模型压缩、量化、剪枝、ONNX、TensorRT/TFLite、推理延迟和资源占用 |
| CV/多模态 | CNN、Transformer、CLIP、目标检测、数据增强、损失函数、评估指标 |
| 机器人 | ROS2、运动控制、传感器融合、PID/MPC、SLAM 基础、系统集成 |
| 工程化 | 单元测试、gtest、CI、代码规范、性能 profiling、异常和鲁棒性 |

## 读博路线

读博不能只说“可以读”，要判断科研可行性。

| 模块 | 判断 |
|---|---|
| 是否适合 | 看科研兴趣、论文/RA、导师资源、长期研究耐心 |
| 适合方向 | Robotics、Embodied AI、Edge AI、Computer Vision、Embedded AI、Autonomous Systems、HRI |
| 优势 | 工科背景、项目、实习、海外硕士、实验室机会 |
| 短板 | 缺论文、缺长期科研、缺明确 research question |
| 补强 | 找导师 RA/毕业设计、读论文、写 proposal、争取推荐信/投稿 |

## 就业与读博双轨时间线

| 阶段 | 就业准备 | 读博准备 |
|---|---|---|
| 入学前 | 技术简历、项目库、C++/OS/算法复习 | 筛导师、整理项目报告 |
| 入学后 1 学期 | 选课、课程项目、暑期实习投递 | 找 RA/毕设、读论文 |
| 暑期前 | 实习面试、技术题、项目深挖 | 明确 research direction |
| 暑期/秋招 | 实习产出、秋招提前批、正式批 | 推荐信、proposal、PhD/RA 申请 |

## 国内主线表述

如果用户说主要关注国内：

- 根据候选人实际毕业日期、应届资格和本轮求职目标确定届次与招聘阶段，不固定为某一年秋招。
- 只有材料确有海外学校或经历时才纳入匹配依据；是否展开海外路线由候选人目标决定，不预填学校或地区。
- 公司类型写国内赛道，不写具体薪资承诺。
- 读博写国内/港新/联培为可选，不把海外 PhD 作为默认主目标。
