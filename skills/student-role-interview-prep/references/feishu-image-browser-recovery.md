# 飞书后台验收：能力发现与故障恢复

用于正文、图片和阅读效果的实际检查。默认后台执行，不抢焦点、鼠标、键盘或剪贴板；工具故障不自动产生前台授权，也不把“请确认切前台”作为验收默认下一步。用户已明确授权本任务前台操作时，只在该范围内使用，不重复询问；没有该授权就继续后台能力发现，并准确保留无法完成的项。

仅续验收时复用原页和已有清单，不重研公司、重写正文或再建页面。所有UI调用服从当前工具文档和首次调用/重置约定，不转用shell、AppleScript、复制Cookie、另开收费浏览器或改账号绕过。

## 先分清失败发生在哪一层

| 层次 | 能证明什么 | 失败不能推出什么 |
| --- | --- | --- |
| 浏览器/会话发现 | 当前有哪些浏览器类型、实例及可用API | 某次高层入口超时不说明后台浏览器整体不可用 |
| 标签获取/导航包装层 | 找到目标标签；部分入口同时急切读取AX（辅助功能树） | eager AX超时不说明标签不存在，也不说明较底层tabs/DOM读取失败 |
| DOM/文字状态 | 当前目标、章节、正文和可定位元素可读 | DOM成功不说明图片已经显示清晰或版式合格 |
| 截图/真实渲染 | 当前视口图片、边界和文字实际呈现 | 截图失败不说明正文或媒体损坏；首屏成功不说明全篇通过 |
| CLI/媒体/导出 | 结构、版本、媒体存在、原件尺寸及导出版式 | token、哈希、PDF正常不能替代在线逐图显示检查 |

## 后台发现与恢复顺序

1. **锁定目标和完整清单。** CLI读取当前文档、父级、所有者、修订号和全文；按章节列每张图的block ID、token/非空`src`、图注及顺序。核对已有证据仍对应当前版本，先保留有效媒体。
2. **读取当前能力文档，刷新浏览器清单。** 工具会话重置后重新按首次调用约定初始化。若文档提供 `cua.listBrowsers()`，按本轮返回的 `type` 识别后台浏览器（如`iab`），取得当前实例ID；实例数字会变，不保存或硬编码旧ID。没有该API时用当前受支持的发现入口，不猜参数。
3. **已有目标先复用。** 高层创建/`cua.getTab`调用超时时，先查标签清单，确认动作是否已生效。当前文档支持时，通过 `cua.getBrowser({id: 当前实例ID})` 取得浏览器句柄，再使用其 `tabs.list()`、`tabs.get(当前标签ID)` 查找/取得目标。该路径与高层getTab的自动AX包装可能不同；不能把换一个同义入口当不同通道，也不能把高层超时泛化到它尚未测试的后台DOM能力。
4. **文字与视觉分开取证。** 当前文档支持时用 `tab.playwright.domSnapshot()` 核对真实标题、URL、章节与正文；再查当前所选浏览器及同一层标签句柄的截图、滚动、章节定位API，按文档取得实际画面。低层Tab的`screenshot({fullPage:false})`与高层CUA Tab的`getScreenshot()`可能不是同一接口；只使用当前句柄文档支持的方法，不能因名称相似混用。DOM通了就继续可做的全文和结构检查，不宣布视觉通过。截图通了再按清单逐图、逐节检查。
5. **确需新标签时才创建。** 当前文档允许时通过已有后台browser句柄创建并导航；超时先列表读回。`visible:false`被明确报不支持时，只移除不支持参数，按文档确认该能力是否仍后台；不能为隐藏参数反复重试，也不能据此改成前台浏览器。
6. **有界恢复。** 相同层次、相同参数和同类超时连续两次，停止原样重试；核对一次会话与参数，尝试尚未测试且文档支持的后台路径。记录每条路径的结果：包装层、DOM、截图/滚动分别怎样。某条路径返回真实原页即复用，不重建。确实可用路径已尝试且仍缺视觉能力时，保留准确的未验范围，继续其他独立检查；不要求用户切屏来替工具故障收尾。

以上API是能力匹配示例，不承诺所有环境存在。必须以当前工具返回的文档为准；不得固化实例ID、标签ID、AX索引或未经文档确认的方法。应报告具体失败层次和实际尝试结果，不笼统写“后台不可用”。

## 逐图与长文检查

优先真实目录定位，再在正文区域后台滚动，正常桌面阅读宽度下检查：加载、四边、中文/数字、字号、箭头起止、分支、终态、底部说明、图注及相邻讲解。长图连续覆盖所有部分；一屏放不下与真实裁切分开判断。合并文档逐家公司检查，不只看首屏或第一家公司。

缺图、字小、错字、错误连接或错位得到真实证据后，才在原页局部修复；回读并重验全部受影响章节。仅工具截图异常时不重复上传、不重画、不改媒体，不用新页掩盖故障。大幅改稿还需完整导出或等价渲染检查长文与表格，但导出不能自动替代在线图片验收。

## 其他可观察异常

| 异常 | 处理与证据 |
| --- | --- |
| 创建/导航超时，结果不明 | 列标签与当前URL，复用已创建的唯一目标；不重复创建 |
| Raise/刷新返回成功，画面白屏或旧内容 | 成功回执不算显示证据，重核URL、标签与本轮画面；没有前台授权不Raise |
| Chrome AX有标题但正文缺失，截图白屏/离屏 | 先回到后台能力分层判断。仅在已有明确前台授权且实际观察到全屏状态时，才可按文档临时退出全屏；不能把历史恢复经验写成所有白屏根因 |
| 状态树与截图不对应，用户切走/收起标签 | 重新观察目标；不沿用旧索引、不恢复全部用户标签、不抢回焦点 |
| 中文查找无命中或赋值没触发事件 | 改用真实目录/后台滚动；输入值正确不等于定位成功 |
| paste冲突或出现其他文本/网址 | 停止输入，读取最新状态；误粘网址不是新目标，不能补粘到正文。回到后台路径 |
| 修订变化但正文相同/出现其他编辑 | 比较真实块内容；保留并发修改，只报告实际比较过的保护范围，不整页回滚 |

## 证据与完成门

任务临时记录或已有manifest的 `visual_contract.browser_qa` 保留：目标与当前修订、后台路径及失败层次、检查章节、实际图片数、每图显示宽度/实时证据、检查项、问题与状态。数目按本轮清单填写，不固定张数。证据仅留本地任务记录，不写进学生正文。

`passed` 要求本轮清单内所有必需图片都在真实网页查看、图中文字与关系逐项检查、必要修复复验、全文阅读路径及保护范围核对完成。DOM全文可读但没有截图/实际画面时，分别报告“文字/结构已验证”和“图片实际显示未验证”；未查看的具体图片和失败通道列为`partial`。不得以打开网页、旧首屏、空白截图、CLI成功或PDF代替通过。
