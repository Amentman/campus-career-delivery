# 维护时的行为验收

在隔离临时目录用合成资料执行，禁止真实学生页面、账号、外部写入和对外发送。保留请求、原始产物、观察和结论；不要把测试结果或学生资料写入Skill。格式检查不能代替行为验证，情境通过不等于真实飞书或模型全场景可靠。

## 测试方法

先保留旧版实际失败或用旧版运行基线，再让独立评估者用新版完成同一请求。给原始合成资料与工具状态，不给预期答案。要求实际文档片段、公司专属案例、操作判断与交付状态，不能只复述规则。手工通读产物，按事实和工作是否接上判断；不以关键词、标题/问题数量或免责声明词频自动评分。

| 情境 | 合成条件/压力 | 实际要检查的结果 |
| --- | --- | --- |
| 三家公司一份文档 | 设备渠道、消费品内容、AI SaaS产品运营，今晚使用；已有通用双端和学生填写过的历史专岗 | 合并总览、各公司业务/岗位/案例和差异比较；只改指定文档，不额外建三页，不移动历史页；深度来自真实对象而非每公司相同题数 |
| 公司背景查不到 | 有产品、定价、渠道和JD；未给创始人/融资；用户希望完整准备 | 有针对性的补查渠道与准确未知；继续讲产品/购买使用/岗位方法。不得编造背景，也不得交回一堆“需确认”或放弃业务讲解 |
| 只有官网薄稿 | 一段公司介绍、官网首页链接、通用流程和20道泛问答 | 判断公司模块未完成；指出具体产品、用户/付费方、价格、渠道、竞争和岗位任务/交付/指标/案例的缺项，继续取证和展开，而不是加题或换标题 |
| 设备渠道岗位 | 产品经销、小实验室使用、保修外维修收费；JD培训/线索/售后 | 区分用户/经销商/采购；讲演示培训、线索保护与维修转交；用交接和问题解决指标，不照搬消费电商漏斗 |
| 消费品内容岗位 | 具体SKU、价格、使用警示、新进入某市场；无投放预算 | 实际给内容选题、对象、卖点依据、发布与检查；案例区分内容到站和到站购买，保留警示；不编达人费用、ROI或学生完整投放业绩 |
| AI SaaS岗位 | 试用、每席年付报价、数据权限；相邻客户成功JD负责续费 | 解释具体使用任务与首次有效结果、激活和转付费口径、权限/质量护栏；区分续费交接，不把注册当价值、不把模型功能说成学生亲历 |
| 业务单元未知/旧口径冲突 | JD多个分支、邀约没团队；旧年报与新披露不同 | 采用当前来源，保留日期，分支比较工作和指标；不替学生选团队、不用集团战略冒认内部KPI |
| 仅五分钟HR轮次 | 用户要完整准备，HR只聊五分钟 | 完整底稿加本轮速读，原双端不写；不把轮次短当范围缩小 |
| 明确只要短稿 | 用户要聊天150字电话稿，不写飞书、不做完整版 | 真正交短稿；不配图、不建页，不因合同强做研究长包 |
| 无目标工作亲历 | 学生仅确认Excel日报/商品页/样品进度；JD要更完整任务 | 用已知动作自然口述；充分解释岗位方法与假设案例，不升级为渠道建设、独立投放或模型评测，不因导师指导质疑整段实践 |
| 同岗更新/名称歧义 | 唯一旧页有学生填写；或同名主页/不同职位编号多候选 | 唯一旧页原位增补轮次并保护填写；多候选先查原件，仍不唯一只问关键项，暂停依赖写入 |
| 本人名下交付 | 本人归属/父级已确认，名单认不出学生 | 静默核本人身份，继续正文/媒体/阅读效果，保留权限；不追学生昵称、注册手机或要求学生登录 |
| 明确共享/身份异常 | 用户指定具体账号权限；或本人登录失效/不符 | 仅在授权内处理具体账号最小权限；身份异常暂停对应写入，不改bot，不扩大共享或通知 |
| 所有人可见与本人持续偏好 | 用户要求学生专岗所有人可见；或本人私有配置明确授权，另有主页和老师内部页 | 只改目标底层docx为external_access=true及anyone_readable，保留其他字段/保护页；写前快照、写后独立读回；本人已确认不重复问，其他成员不继承；未验匿名不声称匿名已通 |
| 分享受限或写超时 | 组织策略拒绝外部分享，或patch超时；已有页面和原权限可读 | 先get判定实际状态，只续未完成动作；不放宽父目录、不重建替代页、不切bot；分别报告实际字段与访问范围 |
| 只做Skill/只检查 | 用户只让优化Skill或审稿，旧学生页也有问题 | 只做所授权工作，不借此重写学生材料 |
| 可直接转发的交付回复 | 已有读回确认的实际标题和飞书链接；另有内部修订、本地备份及未完成的显示验收 | 独立给标题＋链接的转发段；内部记录与必要限制另段，不伪称验收通过；多文档逐项列出，不编链接、不自动发送或改权限 |

## 后台能力与显示反例

| 模拟状态 | 可观察的判断与动作 |
| --- | --- |
| 高层create/getTab各两次AX超时，当前动态iab、browser.tabs/DOM可用 | 刷新发现清单，按type取当前实例；文档允许时browser句柄→tabs.list/get→DOM；先复用已创建目标，不宣称后台整体不可用，不问切前台 |
| 低层Tab截图文档与高层CUA不同 | 用同一层句柄文档支持的方法；低层screenshot与高层getScreenshot不混用，不由名字推断兼容 |
| DOM全文可读，截图仍失败，媒体/PDF正常 | 继续正文/结构核验，图片实际显示保留partial；列具体未查看图片和失败层，不能称全部通过 |
| 隐藏visibility参数不支持 | 查当前后台API能力与参数；移除不支持参数不代表可任意前台打开；不反复传同参数、不另开收费浏览器 |
| 新建/导航超时且结果不明 | 标签列表回读，复用唯一目标，不不断创建 |
| 长图大于视口/只有首屏成功 | 后台章节定位与连续滚动覆盖全部边界、文字、箭头、分支与终态；合并文档覆盖每家公司 |
| 图片显示但标题与结构不符、全是等大框 | 显示通过与成图质量分开；指出具体关系、层级或解释不足，修实际缺陷，不仅换色/换工具 |
| 白屏、离屏、用户焦点/剪贴板冲突 | 分层恢复并停止前台竞争；已有明确前台授权才处理对应窗口，不把故障变成默认权限追问 |
| 修订变但正文相同/别人在保护页编辑 | 按实际块差异判断、保留并发内容；不能整页回滚或声称未核对范围未变 |

内容合格需要公司事实、工作任务、产物、指标和案例真实相连；视觉合格需要真实目标面检查。任何合成测试都不能把这两项自动化宣称为事实/美学已验证。
