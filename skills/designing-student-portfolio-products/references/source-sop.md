# 权威基础 SOP 来源

## 三份固定必看材料

所有作品集的前置资料按以下顺序提供完整标题和可点击链接，三份都要看：

1. [用 12 个核心原理看懂 AI Agent，17 分钟讲清楚](https://www.bilibili.com/video/BV16J7s67EXV)
2. [从 LLM 到 Agent Skill，一期视频打通底层逻辑](https://b23.tv/8zQO6es)
3. [WorkBuddy 使用教程](https://www.bilibili.com/video/BV1gKY563E1Q/)

WorkBuddy 教程的必看要求与实操工具选择分开：看完教程后，可以使用 WorkBuddy 或 Codex 完成一次小改动。其他学习材料一律列为选学或按需查阅，不因基础弱而追加必看课程。项目实现、真实调用、测试和现场讲解仍按产品标准验收，不以额外阅读量代替实际能力。

某份链接失效时，先查找同一材料的有效入口；仍无法取得则明确记录缺失，不静默换成另一门必看课。

## 权威 SOP 的其他教学口径

只有本轮需要团队额外的学生分层、AI Coding 执行规则或导师口径时，读取当前成员提供的组织 SOP。入口从本轮输入或成员私有配置的资料映射取得，按 [团队配置](team-setup.md) 定位；本公开包不包含作者的生产文档。

未提供组织 SOP 时，使用本目录完整 PRD、责任分工、基础学习和验收合同作为默认。确实依赖组织额外口径的部分保留待确认，其他规划继续；不把无法访问某个组织文档当作全部四件套的必然阻塞。

## 使用规则

1. 已提供组织 SOP 时，它是动态来源；用当前成员的 `lark-cli --as user` 解析并读取所需章节，记录修订与资料截止日，不把历史摘要当当前版本。
2. 优先读取：六步执行流程、学生分层、基础资料、定方向和技术方案、AI Coding 执行规则、最终交付与验收。
3. 三份必看清单固定保留；其余资料按当前学生需要选取并标明选学，不把内部案例、其他学生姓名、导师备注或内部链接复制到学生可见页面。
4. 不修改此 SOP。学生作品集的最终交付写入该学生唯一主页或用户指定文档下的独立子页面。
5. 若当前账号无法读取，保留为 `Open`，不要凭记忆补造链接、课程或现行要求。
