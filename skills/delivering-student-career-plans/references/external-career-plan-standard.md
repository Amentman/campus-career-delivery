# 学生职业规划：正文结构与内容审阅

## 阅读主线

学生先理解“我适合做什么、为什么这样选”，再理解“工作具体怎样做、有哪些公司和待遇”，最后知道“补什么、怎样改简历、怎样投”。按这条主线写完整正文，不能用表格字段齐全替代解释。

默认使用下述首屏与八章。标题可适配学生，用户已确认的结构优先；不为凑章节拆分内容。只有一个方向时也保留公司、项目、简历和投递之间的联系。

### 结构已认可，但阅读负担过重时

沿用已认可的章节和有效判断，先确定每节要帮助学生完成的阅读任务，再重排表达。方向比较、公司待遇、补强产物等并列信息用紧凑表；流程、条件分支和反馈关系用紧邻讲解的图；原因、取舍与案例保留短段落。表格按主题拆分，单元格只放可比较的要点，不把连续讲解整段搬进去。

保留支撑选择的事实、具体案例和推理，删除重复背景、同义提醒和无信息过渡。岗位小节可采用“一个具体工作场景 → 适配与门槛对照 → 短段落解释取舍”的节奏；复杂场景再加局部图解。提纲化、全表格化与单纯增加图片都不能替代这次重写。

## 首屏：方向结论与个人简历

用一小段直接给出：当前建议主线、补充或条件性路线、主要依据、近期第一步。明确这是基于现有证据的建议；尚未确定最终意向时仍给有依据的排序与切换条件。

接“个人简历”及原 PDF/Word 文件块。原件图片可以辅助浏览，不能替代二进制附件。首屏不放内部事实标签、费用、服务销售说明或生成过程。

## 1. 学生现状与求职目标

用相互衔接的短段落完成三件事：

1. 影响选择的教育、届别、经历、城市、到岗和工作偏好；
2. 把具体经历归纳成可迁移能力，同时指出最影响进入岗位的缺口；
3. 解释这些能力与偏好为什么导向首屏建议，哪里存在取舍。

不要重抄整份简历。性格与兴趣用于解释工作方式偏好，不推导为岗位能力。常规未知项集中到末尾；会改变本节结论的未知点在这里说明一次。

## 2. 核心求职方向总览

先用方向地图呈现主线、补充和条件性分支，再用一张紧凑表比较。常用五列：

| 优先级 | 方向与代表岗位 | 适配依据 | 关键补强/进入条件 | 目标城市薪资参考 |
|---|---|---|---|---|

表格负责并列比较，日常工作留到下一章展开。薪资注明城市、实习/全职口径、税前税后、样本日期和性质；个人目标单独写，不能充当市场证据。

多方向应体现不同作用，不能都写“推荐”。所谓稳定线应说明具体稳定来源和代价，不能仅凭公司规模或行业标签判断稳定。

若任务是技术与非技术比较，候选由学生证据决定：研发、产品、分析、运营、解决方案/商务等不必全部展开，但应评估有实质迁移可能的工作。技术背景不自动导向 AI 产品；希望接触人和资源也不自动导向销售。正文保留真正影响选择的比较，说明未选某类工作的具体原因。

## 3. 各方向分别做什么、为什么适合

每个方向覆盖下列内容，按具体场景、比较表和短解释组织，表达形式服从信息关系：

- **在规划中的作用：**主攻、补充还是满足什么条件后切换，为什么。
- **日常工作：**谁遇到什么问题，输入是什么，主要动作是什么，交付什么，与谁协作，怎样检查结果。流程复杂时配工作图；图紧邻讲解。
- **为什么适合：**连接学生某段经历中的实际动作与岗位要求，解释能迁移什么、尚未证明什么。不能只写“专业对口、沟通好、学习快”。
- **取舍与进入条件：**这条路线满足哪些偏好，又牺牲什么；最关键差距补到什么程度可以投。
- **可以检索的岗位：**真实岗位名称、常见别名，以及名称相似却工作不同的边界。

例如，研发岗用实验与工程结果证明问题解决，产品岗需要需求取舍与验证证据，解决方案岗需要客户问题澄清、方案讲解与交付协作证据。不能用同一个“做一个 AI 工具”覆盖所有路线。

学生应能在本章之后用自己的话说出这份工作一天怎样展开、自己为什么值得尝试、最大的门槛是什么。做不到就继续补讲解，不能只增加岗位名或表格。

## 4. 行业、公司与岗位薪酬选择

先解释岗位与行业的关系：同一职业在哪些业务场景存在，这些场景对学生有什么不同。行业跨度大时用矩阵；简单映射用文字即可。

随后交付两个相互关联的层次，详见 `planning-and-project-contract.md`：

1. **具体机会样本：**每条保留路线至少一个真实公司岗位，职责、城市、阶段/届别、状态、薪酬待遇、差距、来源与日期在附近对应。岗位与待遇可分小表或短小节，避免超宽表。待遇未公开时补同职业、同城、同阶段的可比依据，明确比较边界。
2. **分层公司池：**第一批重点、补充、选择性冲刺/长期关注，均给具体公司名与分层理由。第一批应优先选择现有证据能承接、工作方式符合诉求的团队；公司名气不能代替岗位匹配。

当前岗位样本、历史画像与长期研究池区别说明一次。未来届次尚未开放时保留真实的参考阶段，不把旧届岗位当可申请清单。AI Agent 路线适用时才细分大厂应用/平台/评测与核心算法门槛，同时保留中小或垂直场景公司池。

薪资比较直接服务学生的选择：固定部分、浮动部分与影响生活的安排分开；共同未披露项集中说明，只有会改变取舍的差异在对应样本强调。不能用成片“待确认”代替继续研究，也不能编造福利或平均薪资。

用户把待遇列为核心时，在每条路线内形成多家公司对照，覆盖可查到的不同报价与工作安排；一条样本不能代表整条路线。可拆成两张相邻小表：“公司／岗位—招聘展示薪酬—年额口径—状态与资格”和“同一公司／岗位—已披露福利与培养—工作安排—个人取舍”。每组后用短段落解释该学生优先研究谁、较高报价多了什么要求、较低报价是否有具体培养或工作条件支持。样本数量随证据决定，不用重复地区、编号或批次凑数。

公司名单和研究依据必须进入正文，不能只留在内部文件或聊天回复。

## 5. 补强项目与证据

先解释本章补哪条缺口，再展开项目。应届生通常 1—2 个，数量服从实际；已有项目足以支撑时优先深化，社招优先复盘真实经历。参考规划中的项目复杂度不迁移给其他学生。

每个项目用简洁标签加讲解，形成完整闭环：

`对应岗位 → 当前缺口 → 具体场景/用户 → 学生要做的工作 → 可检查交付物 → 达标条件 → 简历与面试用途`

交代数据/权限、计划状态、最低可演示版本和最终验收。技术项目提供代码、评测与失败复盘；产品/业务项目按岗位需要提供需求、分析、方案、验证或客户沟通证据，不强制都写代码。AI 项目的复杂度按真实缺口决定，不默认堆 RAG、多工具、记忆或多 Agent。

反向核对本章项目是否能支撑第4章岗位样本的核心工作。项目未完成时只能写为计划；完成并通过复盘后才进入对应简历。

## 6. 简历版本规划

先说明哪些版本现在即可用，哪些版本依赖新证据。常用四列：版本、主投岗位、现有经历突出什么、达标后新增什么。

简历分版是突出不同证据与顺序，不改写事实。每版与本页推荐岗位对应，条件性路线不必立即占用同等制作时间。现有经历可以支撑申请时先形成可投版本，不等所有补强项目完成。

## 7. 投递与面试策略

按“投递顺序 → 单岗筛选条件 → 反馈调整”展开：

- 各批次投什么团队和工作内容，为什么这个顺序；
- 如何核对城市、资格、到岗、工作方式、待遇及核心能力；
- 过筛低时先查岗位/简历匹配，面试暴露能力缺口时补对应证据，条件性方向获得何种反馈后提高或降低投入。

路线排序是当前判断，投递或试做用于检验明确假设。不要以“先全部试一遍”代替判断，也不要以补项目为理由暂停所有申请。

正文先解释补强项目、再讲简历和投递；实际执行可以并行。已有证据支撑的岗位现在投，依赖新证据的岗位达标后投。两个条件在本章与时间线保持一致。

## 8. 行动时间线与近期重点

按当前日期、届别、到岗窗口倒排，避免照搬参考日期。时间线应显示证据补强、简历、岗位研究/投递、面试反馈的并行关系和关键门槛。

结尾保留“近期最重要的三件事”与“后续需要本人确认”。后者只列会改变路线、公司池或节奏的信息；附上信息将影响什么。不要为待确认事项另造冗长章节。

## 参考使用与模式变化

- **有参考文档：**完整读取其正文和关键图表，学习问题顺序、解释深度、图文衔接及阅读节奏；以当前学生证据重写。参考中的内部销售内容、缺失附件和过时岗位不能照搬。
- **架构对焦：**用户只要目录或先讨论时，给八章主线、核心表字段、项目—简历—投递关系与图解位置；不提前写完整正文或飞书，也不规定固定图数。
- **标准学生版：**以上即成熟完整的默认交付。是否写飞书遵守当前任务及会话授权，唯一落点已确认则不重复问；讨论和检查保持只读。
- **扩展研究：**按明确要求增加 JD 深度、经历矩阵、公司/城市覆盖或独立白皮书，不以重复解释增加篇幅。
- **局部修改：**保留用户已确认的结构与有效内容，只改指定缺口及其必要关联，不套新模板重写全篇。

## 内容审阅：在排版与写入前做

逐条用正文中的具体段落作证；发现问题先修正文，不让用户替 Agent 找缺口：

1. **判断：**读完首屏能说清主线、依据、取舍和切换条件？如果只剩“都可以/先试试”，回到方向研究。
2. **深度：**每条路线能解释日常工作、个人证据、真实门槛？如果换任何学生名字都成立，重写适配依据。
3. **市场：**每条路线有同口径的具体岗位、公司与薪酬依据？待遇是核心时，是否能在同一路线内比较多家公司的现金、培养和工作安排，并作出针对本人的取舍？未知项只保留确实查不到的部分，未完成研究如实交代。
4. **连贯：**抽一条岗位样本，从职责追到缺口、项目交付物、简历版本和投递门槛，能否一一对应？“同属 AI/互联网”不构成对应关系。
5. **行动：**学生知道现在能投什么、先补什么、何时改变投入？时间线是否错误阻塞已有证据支撑的投递？
6. **阅读：**从实际正文定位方向差异、具体待遇、申请优先级和下一步，是否需要反复翻找或读穿长段落？短段落讲原因，表格做同口径比较，图解释关系，步骤承载动作；重复风险与未知信息集中表达。不能把所有正文塞进表或图，也不能删掉案例、理由和行动门槛。

之后再验收事实、来源、附件、父级、唯一性、完整读回与渲染。脚本关键词只检查覆盖线索，不证明判断正确；图数、页数和 revision 增加均不作为内容质量证据。

图应紧邻解释，按实际阅读宽度检查中文、分支、终态、字号和留白。默认把清晰解释图嵌入飞书正文；有效画板可保留，载体服务阅读。导出必须确认首尾完整并逐页看图，遇截断先核对真实内容和媒体验证，再选择可追溯的完整渲染，不把反复导出当作修复。
