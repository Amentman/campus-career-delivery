# 从素材写成文章

## 先弄清读者在卡什么

熟悉业务的人写材料，会选择哪些内容需要解释、哪些可以直接说。给初学者的群面讲义要解释如何从题面找到目标；给熟练导师写备课说明，可以直接谈追问与判断差异。不要把聊天里已经说清的背景重新铺成一页，也不要把读者不知道的术语当成共同常识。

内部写一句“读完以后，读者能……”，据此检查内容。它是写作工具，不必成为正文里的“学习目标”卡片。资料不足以支持方向判断时，先讲清可以判断的部分及真正影响选择的缺口。

## 学参考的组织，不搬参考的口吻

完整阅读本次指定的参考，记录四件事：

| 看什么 | 要找到的实际内容 |
| --- | --- |
| 开头 | 读者最关心的问题，哪些背景被省略 |
| 章节 | 前一节给后一节提供了什么理解条件 |
| 案例 | 题面、原因、取舍、示范表达、追问分别讲到多深 |
| 阅读节奏 | 连续讲解、例子、比较表、练习和图在什么位置切换 |

给重要观察保留源位置，防止只记住漂亮标题。有多篇参考时，选取与本次文体相关的优点，不把各篇目录拼在一起。学习文章并不证明它由人写成，也不证明公司信息、招聘比例或薪酬数据仍然有效。

面试攻略类参考可借鉴的顺序是：先理解招聘环节与面试官角色，再解释考察原因，之后进入具体问题、案例和训练。它解决了“还不懂为什么，就被要求背答案”的问题。本次内容没有这些环节时，不照搬此顺序。

参考中的宣传开场、密集表情、绝对化通过率、强行总结和重复提醒不随之继承。参考原文、私人链接和学生材料不进入公开Skill；只保留抽象后的写作方法和独立编写的教学例子。

## 章节有分工，段落有承接

先把素材按读者需要理解的顺序排好，再命名章节。例如，解释活动投入是否合理，需要先明确目标，再区分触达和成交，然后讨论成本与未知数据；直接堆“用户思维、数据驱动、经营意识”会让读者不知道从哪里下手。

已经确认预算不能增加，下一段就讨论预算内怎样比较方案。后面遇到同伴坚持追加预算时，可以引用条件并补充回应，没必要把预算规则重新讲一遍。关键限制可以在示范话术里自然重现；周围的解释应提供新内容。

一句话同时有三个抽象概念时，找到实际主语与动作，再确定因果。不要只把“赋能”替换成“帮助”。“数据帮助业务增长”依旧没有解释是谁看了什么数据、据此做了什么决定。来源没有这些细节时，收窄句子，不捏造细节填空。

## 把核心例子讲到能照着推

重要例子要让读者理解题意、判断依据和具体做法。按需要继续展开例外、追问或一次练习；不是每个例子都要凑满固定栏目。

例如，说明“不要只看曝光量”，需要指出曝光与目标之间还有哪一步，以及这一步为什么可能让结论改变。若目标是成交，同样多的曝光不保证同样多的订单；若目标就是让更多目标用户看到信息，曝光则可以是直接指标。这样学生才能知道什么时候该用这条建议。

示范表达之后，解释其中最值得学的一两处选择，不把整段话再复述一遍。需要练习时改变一个条件，让读者重新判断，或要求用自己的话完成同类回应；重复抄写参考答案无法验证理解。

案例缺少转化率，说明它为什么影响选择即可。不要为了“具体生动”补出测得结果。允许在明确的教学假设下演算，但假设、演算与真实结果始终分开。

## 区分该删的和该留的

可以删除：没有新含义的开场、重复收尾、只宣称重要而不解释原因的段落、读者无需知道的生成过程。把能提供证据或改变决定的内容留下。

“全面覆盖”“形成完整闭环”通常可以直接删掉。岗位工作内容、待遇构成、反对理由、预算上限、适用条件与待确认日期，即使让文章变长，也可能不可删除。压缩前先核对用户要求和业务Skill的必需内容，不能用写得短替代写得完整。

改完后对照原文的独立信息。“可能改善”不能变成“已经提升”，“参与”不能变成“主导”，“导师带教下完成”仍然是本人实际实践。事实冲突单独处理，不能借润色静默裁决。

## 按实际阅读路径通读

从首屏读到结尾，检查能否顺着解释理解案例、找到相关段落、知道怎样操作。发现某处还得猜作者的意思，就补必要的关系；发现连续三段强调同一件事，就合并。

再看标题、引语和图表。标题说清该节问题，引用给出可参考的表达，表格保持字段可比，图解承担真实关系。不要把加粗、标题或卡片数量当作层级清楚的证据。
