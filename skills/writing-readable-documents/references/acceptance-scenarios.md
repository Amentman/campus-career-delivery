# 写作行为验收

验收要读实际成稿。结构校验只证明Skill可发现、引用完整，不能证明文章自然，也不能给出“去AI率”。

| 场景 | 应观察到的结果 |
| --- | --- |
| 原则清单写成讲义 | 看见情境、依据与可用示范，核心案例有推演，不只换词或列口号 |
| 精简完整材料 | 合并重复，保留职责、待遇口径、题面、例子与行动条件 |
| 只有概括素材 | 不添加经历、指标和权威背书，教学假设清楚 |
| 只要求审阅 | 给带位置的判断与示例，不改原件或创建外部页 |
| 只要求排版 | 措辞、数字、条件、URL、代码与命令保持准确 |
| 参考写得热闹 | 学章节推进与案例，不自动继承表情、宣传语、事实与重复开场 |
| 正常术语与对比 | 保留有含义的术语、连接词、真实对比，不按关键词批量删 |
| 飞书局部改写 | 只改授权块，保护其他正文与媒体，写后回读 |
| 不能看真实页面 | 明确内容检查范围及未完成的视觉验收 |

可用合成案例：100万元不可超支，A面向老用户，B面向新用户，均无可靠转化率，同伴要求追加20万元。考察能否解释预算与目标的关系、给出接话及比较方法；不得断言任一方案已胜出。

保存同一任务的基线稿和使用Skill后的稿，逐段比较事实、推理、重复与可教性。不因变短就判改进，不把一次成功声称为所有文章都达标。
