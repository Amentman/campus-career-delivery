# 风格 C · 故事案例体

## 一句话定义

用一件真实且具体的事引出判断，再解释读者可以怎样处理相似情况。

## 适用场景与长度

真实客户对话、咨询问题、本人经历或明确发生的事件。

通常500—1000字；事件约三分之一，分析与建议约三分之二，按材料调整。

## 写作结构

开头交代谁在何时遇到什么问题；用2—4句话保留关键动作和必要原话；提炼一个与事件直接有关的判断；解释机制，必要时补对比例子；以方向或动作结束。无真实事件时改用知识解释，不编“朋友问我”。

## 自包含示例

【模拟示例，只说明结构】
假设用户提供一段真实对话：客户说“我看完还是不知道这一档包含什么”。成稿可以先保留这句原话，再解释服务说明缺少具体产物、交付次数或边界，最后给出应补的信息。

本例没有真实客户身份和结果。写作时不能把“假设”删掉后变成本人的客户案例；应替换为用户实际提供的事件。

## 要点、边界与相邻风格

客户与朋友脱敏；只保留必要场景，不展开全部聊天。具体金额、业务结果和频率须有来源；一个个案不能自动推出普遍规律。对话复述不改变原意。C借事件解释判断，D侧重内心思考，F侧重两件事的结构对应，B先提出争议命题。

## 调用方式

读取本文件，再回到用户提供的素材；只借结构与节奏，不借人物、经历、数字或结果。完成后检查事实可追溯、主线单一、语气符合成员、读者知道下一步。示例无需外部历史文案或个人记忆文件。
